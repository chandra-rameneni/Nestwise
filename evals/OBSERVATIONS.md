## Replay with a free model (OpenRouter, 2026-11-18)

The agent can now use a free OpenRouter model (`llm.py`; NVIDIA Nemotron first, Gemma as backups) to understand messages, and falls back to the rules if no model answers. I replayed 12 messages from the observations above (about 25 requests used).

| Observation | With the model | Fixed? |
|---|---|---|
| O-2, O-5: "show me the results" → "We don't sell results" | Understood as "show results", but the agent still insists on seats and width first | **Understanding fixed; decision not** (needs B18) |

| O-13: "no space" | The model's reply wasn't valid JSON, so the rules took over: "We don't sell space" | **No.** Free models are sometimes unreliable |
| O-20, O-21: "dumber", "looser…" | "Sorry, I didn't understand that" (no more "We don't sell dumber", no reused memory) | **Safe now**, though not recognised as rude |
| O-22, O-23: "how many products…", "what can you help me with" | Catch-all reply | **No.** There's no PRD block for store questions or help, so the agent has nowhere to send them |

**Conclusion:** the model fixes most of the *misreading*. What's left are *decisions* the agent makes in code: asking before showing results (B18), help and store questions, brand and product-name search, and picking from shown results. Those are the Phase 2 change.
